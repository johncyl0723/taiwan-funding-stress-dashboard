# 台灣資金緊俏每日儀表板

公開市場研究用途的台灣短期資金監測工具。追蹤同日 TFSS（90D TAIBIR 初級市場 − 3M TAIBOR）、90D 初次級利差、金融業隔夜拆款與央行 NCD 淨發行。

## 指標定義與限制

| 指標 | 定義 | 來源 |
| --- | --- | --- |
| TFSS | 90 天期 TAIBIR 初級市場利率 − 3 個月 TAIBOR，單位 bp | TDCC ＋ 銀行公會 |
| 初級－次級利差 | 90 天期 TAIBIR 初級 − 次級，單位 bp | TDCC |
| O/N 隔拆 | 金融業隔夜拆款利率 | 中央銀行 |
| NCD 淨發行 | 當日發行金額 − 到期金額，單位百萬元（正值＝淨吸收流動性），另計近 5 個交易日合計 | 中央銀行公開市場操作公告 |

判讀規則與已知限制：

- **TFSS 不是純粹的資金鬆緊指標。** 分子端是票券初級市場（企業信用），減項是銀行間定盤利率，價差同時包含信用溢酬與流動性溢酬，性質接近 TED spread。
- **燈號是相對百分位，不是絕對水準。** 以 120 日窗格為主、60 日為輔，>95 判為異常壓力、>85 明顯緊俏、≥60 開始偏緊。利率趨勢性走升期間分位可能同步墊高，需併看絕對水準與初級／次級利差。
- **百分位採中位排名法**（`(小於者 + 同值者/2) / 樣本數`），避免平盤序列被誤判成極端值。
- **樣本不足時不給燈號。** 未滿 30 個交易日一律標為「待資料確認」；30 個交易日以上但窗格未滿，燈號標示為「暫定」。
- **TFSS 只在 TAIBIR 與 TAIBOR 同日皆有定盤時計算**，任一缺漏該日即為空值，不以鄰日補值。

## 架構

純靜態網站，全部跑在 GitHub 上：

- **前端**：Vite + React，發布到 GitHub Pages
- **資料更新**：GitHub Actions 排程（UTC `0 4 * * 1-5`，即台灣時間週一至週五 12:00）執行 `scripts/refresh.ts`，抓取官方公開資料、計算指標，寫回 `public/data/dashboard.json`、`public/data/history.json` 並自動 commit
- **歷史回補**：每次更新都向官方來源要一整段區間（預設 200 天）而非單日，因此首次執行即可取得約 130～140 個交易日的統計基期，不必等待每日累積；既有 `history.json` 會與新抓取的區間合併，舊值僅在新資料缺漏時保留
- **研究摘要**：規則式模板（`scripts/lib/insight.ts`），依 TFSS 燈號與 5 日變化套用預寫文字，不呼叫任何外部 AI API
- **手動更新**：到 repo 的 Actions 頁籤，選 `更新資料並部署` → `Run workflow`

沒有伺服器、沒有資料庫、沒有登入機制，也沒有任何會產生費用的外部服務。

### 抓取來源的實作重點

- **TDCC TAIBIR**：官網只有「當日」頁面，改用歷史區間查詢（POST ＋ CSRF token ＋ session cookie）
- **TAIBOR**：數字不在網頁文字中，而在公告附的 Big5 CSV。合併「每日公告」（近 40 天）與「月報」（單月全月）即可回補任意長度
- **隔夜拆款／NCD**：央行頁面每頁 20 筆，翻頁回補；NCD 金額只在「公開市場操作資訊」公告內文，「存單申購發行資訊」公告沒有金額，需以標題過濾
- **欄位一律依表頭文字定位**（`90`、`三個月`），官網改欄序時會直接報錯，而非靜默取到錯誤天期
- **降級策略**：TAIBIR 初級與 TAIBOR 為核心來源，缺任一則整批不發布；次級、O/N、NCD 缺漏只讓該欄位為空值

## 本機啟動

```bash
npm install
npm run dev
```

手動跑一次資料更新（會寫入 `public/data/`）：

```bash
npm run refresh
```

跑單元測試（離線，以固定 HTML／CSV 樣本驗證解析器）：

```bash
npm test
```
